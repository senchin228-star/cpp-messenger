# Wiretalk Electron Client

Графический клиент для C++ мессенджера **Wiretalk** на базе Electron.

## Особенности
- **Интерфейс**: Тёмная современная тема Catppuccin Mocha.
- **Поддержка комнат**: Общий чат `#general`, возможность создавать и переключаться между комнатами (`#dev`, `#games` и т.д.).
- **Личные сообщения (Direct Messages)**: 1-на-1 переписка с любым пользователем.
- **Сессионное хранилище**: Все сообщения сохраняются в оперативной памяти во время текущей сессии (без сохранения на диск, как и требовалось).
- **Список онлайн**: Отображение активных пользователей в сети с возможностью в один клик начать личный диалог.
- **Чистый код**: Никаких громоздких фреймворков и сборщиков — чистый, легко читаемый JavaScript (ES6+), нативные модули Node.js (`net`) и стандартный IPC Electron.

## Структура проекта
```
electron-client/
├── package.json        # Конфигурация и скрипты запуска
├── main.js             # Главный процесс Electron: управление окном и TCP-сокетом
├── preload.js          # Мост безопасности (contextBridge) между сокетом и окном
├── run.sh              # Скрипт запуска приложения через electron43
└── renderer/
    ├── index.html      # Разметка экранов (вход, чаты, модальные окна)
    ├── style.css       # Стили интерфейса (тема Catppuccin)
    └── app.js          # Логика интерфейса: состояние чатов, отправка/приём
```

## Запуск
1. Запустите сервер (в отдельном терминале):
   ```bash
   cd ~/cpp-messenger
   ./server
   ```

2. Запустите Electron-клиент:
   ```bash
   cd ~/cpp-messenger/electron-client
   ./run.sh
   # или из корня:
   ./run-electron.sh
   ```
